    如何判断结果

    先在代理客户端选择节点，再开始检测。工具跟随当前代理连接，不会替你切换节点。TUN 模式可选择「直连 / 由 TUN 接管」。

    按次数：每个选中站点分别采样指定次数。按时长：持续采样到设定时间结束。间隔是每次请求结束到下一次请求开始的等待时间。

    成功率：整次检测的成功请求数 ÷ 已完成请求数。受限和失败均计入分母；停止或到时取消的未完成请求不计入。认证检测独立展示。

    响应延迟：HTTP 首字节时间 TTFB，包含代理、隧道及远端响应，不是 ICMP Ping。TCP 可能只连到代理端口，TLS 时间可能包含代理隧道，远端 DNS 无法单独测量。

    ChatGPT：分别测试首页及登录认证站点的网络。首页可达但认证链路失败时，会单独提示；网页或认证域名可达均不代表账号登录成功。YouTube 检测站点连通性，不验证视频播放。

    出口信息仅反映 Cloudflare 路由，分流规则可能让不同服务使用不同出口。自定义站点只检测 HTTP 响应，不能判断完整业务功能。
